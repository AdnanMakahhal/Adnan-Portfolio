# Adnan Makahhal | Portfolio

Personal portfolio for Adnan Makahhal, a UI/UX designer and full-stack developer based in Amman, Jordan. The site presents selected web projects, skills, certificates, and contact details in a responsive Next.js experience.

## Highlights

- Responsive layout for desktop, tablet, and mobile
- Project gallery with website screenshots and technology icons
- Skills and tools overview
- Certificate gallery with links to certificate PDFs
- Contact form that prepares an email message

## Tech Stack

- Next.js 16 with the App Router
- React 19
- Tailwind CSS 4
- Swiper for project and certificate galleries
- Framer Motion for interface animations
- Lucide React icons

## Getting Started

### Requirements

- Node.js 20.9 or newer
- npm

### Install and run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Available Scripts

| Command         | Description                                |
| --------------- | ------------------------------------------ |
| `npm run dev`   | Start the development server               |
| `npm run lint`  | Run ESLint                                 |
| `npm run build` | Create an optimized production build       |
| `npm start`     | Start the production server after building |

## Production Build

```bash
npm run build
npm start
```

## Security Check

Check dependencies for known vulnerabilities:

```bash
npm audit
```
